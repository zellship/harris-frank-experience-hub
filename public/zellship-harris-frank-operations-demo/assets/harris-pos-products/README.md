# Harris & Frank - POS Product Thumbnails v1.0

Paquete de imágenes representativas para poblar el catálogo de demostración del POS.

## Contenido

- `png-1024/`: 17 archivos PNG maestros de 1024 x 1024 px.
- `webp-800/`: 17 archivos WebP optimizados de 800 x 800 px para uso web/POS.
- `contact-sheet.png`: catálogo visual de control.
- `catalog-manifest.json`: relación de categoría, producto, SKU, evidencia y archivos.
- `generation-prompts.md`: dirección visual y prompts de regeneración.

## Reglas de uso

- Las imágenes son representaciones generadas para demo y carga provisional en POS.
- No sustituyen fotografía oficial ni validación física del SKU.
- No se inventaron SKUs. Los identificadores no cerrados aparecen como `POR_VALIDAR`.
- Cuando el nombre del producto no estaba definido en las fuentes, se utilizó una descripción visual y se marcó como `inferido`.
- El archivo recomendado para el POS es el WebP de 800 x 800 px; el PNG queda como maestro.

## Fuentes consultadas

- `SS26 y BASICOS.xlsx`: productos, categorías y SKUs de básicos y SS26.
- `Pedidos en curso Harris & Frank.xlsx`: jeans, chamarra y chaleco/vest.
- `SASTRERIA SUCURSALES GENERAL 2026.xlsx`: presencia operativa de trajes, sacos, pantalones y chalecos.
